# Premium Auto Salon - Статический сайт подряд автомобилей

Полнофункциональный премиум-сайт автосалона, разработанный с использованием HTML5, CSS3 и ванильного JavaScript.

## 📁 Структура проекта

```
bmw-salon/
├── index.html              # Главная страница
├── services.html           # Страница услуг
├── contacts.html           # Страница контактов
├── robots.txt              # Файл для поисковых систем
├── sitemap.xml             # Карта сайта для SEO
├── README.md               # Этот файл
├── css/
│   └── style.css           # Все стили сайта
└── js/
    └── script.js           # JavaScript функциональность
```

## 🎨 Особенности дизайна

- **Тёмная тема**: Фон #0a0e1a с акцентным синим градиентом от #0066B1 до #00a0e3
- **Премиум-внешний вид**: Современный и элегантный дизайн люксового автосалона
- **Полная адаптивность**: Отлично выглядит на всех устройствах (мобильные, планшеты, ПК)

## ✨ Компоненты и функциональность

### 🏠 Главная страница (index.html)

- Заголовок "Искусство вождения" с градиентом

  - Эксклюзивный тест-драйв
- Чередование расположения картинки и текста
- Детальное описание и цены услуг

  - При скролле фон становится более непрозрачным с blur-эффектом

## 🎬 Анимации и эффекты

- **Прелоадер**: Пульсирующий логотип при загрузке сайта
- **Reveal-анимация**: Плавное появление блоков при скролле (Intersection Observer)
- **Параллакс**: Движение фона hero при скролле и движении мыши
- **Hover-эффекты**: Поднятие карточек, изменение цвета, увеличение масштаба
- **Smooth scroll**: Плавная прокрутка при навигации

## 📱 Адаптивность

- **Десктоп** (>1200px): Полная версия с всеми элементами
- **Планшет** (900px - 1200px): Адаптированный макет
- **Мобильный** (<900px): 
  - Бургер-меню вместо горизонтального навигации
  - Карточки в одну колонку
  - Оптимизированные размеры текста и кнопок
  - Скрыта информация о телефоне в шапке

## 🔍 SEO оптимизация

- **Robots.txt**: Указание путей для поисковых систем и ссылка на sitemap
- **Sitemap.xml**: Карта всех страниц сайта с приоритетами и датой обновления
- **Meta-теги**: Описания и ключевые слова для всех страниц
- **Микроразметка**: Schema.org разметка типа AutoDealer на главной и контактах
- **Open Graph**: Теги для социальных сетей (можно добавить при необходимости)

## 🎯 Модальное окно

- Форма с полями: имя, телефон, email, выбор услуги/модели, комментарий
- Закрытие по нажатию ESC, клику на крестик или вне модали
- Валидация формы

## 🚀 Как использовать

1. **Откройте в браузере**: Просто откройте файл `index.html` в любом современном браузере
2. **Разверните на сервере**: Загрузите все файлы на ваш веб-сервер
3. **Локальное тестирование**: Используйте простой HTTP-сервер:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (с http-server)
   http-server
   ```

## 🛠️ Кастомизация

### Изменение цветов
Отредактируйте переменные в начале файла `css/style.css`:
```css
:root {
    --bg-dark: #0a0e1a;
    --color-primary: #0066B1;
    --color-accent: #00a0e3;
    /* ... */
}
```

### Изменение контактной информации
Обновите адрес, телефон и email во всех HTML-файлах:
- Найдите и замените номер телефона на свой
- Обновите адрес салона
- Измените email для обратной связи

### Добавление карты
Замените `.map-placeholder` на реальную карту Яндекса или Google Maps в файле `contacts.html`
